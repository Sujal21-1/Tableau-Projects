##Tableau Data Visualization Projects

A portfolio of interactive Tableau dashboards focused on exploratory data analysis (EDA), business intelligence (BI), and data-driven storytelling using real-world datasets.

Overview
This repository contains a collection of data visualization projects designed to analyze complex datasets, identify trends, and communicate actionable insights for decision-making. Each dashboard is built with a focus on clarity, interactivity, and analytical depth.

Tools & Technologies


Tableau Desktop / Tableau Public


Excel / CSV datasets


Data cleaning and preprocessing (Python where applicable)


Descriptive analytics and exploratory data analysis (EDA)



Core Capabilities Demonstrated


Data wrangling and preparation for visualization readiness


KPI identification and trend analysis across multiple domains


Development of interactive dashboards with filters and drill-down functionality


Visualization of multi-variable relationships and distributions


Translation of raw data into business-relevant insights



Project Domains
This portfolio includes dashboards built across multiple real-world domains, including:


Housing market analysis


Customer reviews and sentiment trends


Airline service quality and performance metrics


General business performance and operational analytics



Key Focus Areas


Identifying patterns and anomalies in large datasets


Comparing performance metrics across categories and time periods


Enhancing interpretability through interactive visual design


Supporting data-driven decision-making for stakeholders



Objective
The goal of these projects is to demonstrate applied analytics skills in Tableau, with emphasis on transforming raw datasets into meaningful visual insights that support business understanding and strategic decisions.
